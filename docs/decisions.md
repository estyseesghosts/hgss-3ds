# Decisions log

Choices made during implementation that `gameplan.md` did not specify. The
plan's own decisions table is authoritative for everything it covers.

| Date | Decision | Why |
| --- | --- | --- |
| 2026-10-30 | Private folder is `~/hgss-private` (`mwccarm/`, `NitroSDK/`, `roms/`, `saves/`), created by moving/extracting the archives the user left in the project root. | User instruction. |
| 2026-10-30 | The supplied Nitro SDK is `NitroSDK-4_2-071210-jp` (the same archive pmd-sky uses), not the `NitroSDK-3_2-060901` named in the decomp's `scripts/setup-macos.sh`. We use it and let the matching build be the test. | Only archive available; the decomp's `INSTALL.md` says "a compatible Nitro SDK". Risk tracked in `docs/progress/phase-0.md`. | **Superseded 2026-10-30 (later): the canonical SDK is `NitroSDK-3_2-060901` (archive SHA256 `0ee935e3…`, the hash in the decomp's setup script); the 4.2-jp archive was the wrong one and is kept only as `NitroSDK-4_2` in the private folder.**
| 2026-10-30 | `install-ds-toolchain.sh` copies the whole `mwccarm/` tree plus `license.dat`, not only `2.0/sp2p2`. | `common.mk` also uses `2.0/sp2p3` (lib/NitroSDK, lib/MSL_C), `1.2/sp2p3`, `2.0/base`, `sp1`, `sp1p5`, `sp2`; license is found via `LM_LICENSE_FILE=tools/mwccarm/license.dat`. |
| 2026-10-30 | LCF/response templates are copied from the SDK's `include/nitro/specfiles/`, not from a "templates" folder in `/private`. | That is where the SDK (and the decomp's setup script) has them. |
| 2026-10-30 | Container runtime is OrbStack (Apple silicon, amd64 via Rosetta); Dev Containers CLI from npm. | User approved installing OrbStack with brew. |
| 2026-10-30 | `savetool` discovers slot sizes from footers instead of hard-coding them (`--layout` overrides). | Slot sizes depend on compiled struct sizes (`gSaveChunkHeaders` size funcs); hard-coding would be a guess. |
| 2026-10-30 | Container base is Ubuntu **24.04**, not the decomp's 22.04. | devkitARM (devkitPro pacman, r68) is linked against glibc 2.36; on 22.04 `arm-none-eabi-gcc` fails with `GLIBC_2.36 not found`. The `COPY --from=devkitpro/devkitarm` route has the same problem (Debian bookworm binaries). |
| 2026-10-30 | devkitPro installed with its apt repo + `dkp-pacman -S 3ds-dev`, key fetched with `wget -U "dkp apt"`. | `apt.devkitpro.org` returns a Cloudflare 403 to other User-Agents; the official installer script uses `dkp apt`. |
| 2026-10-30 | Wine is **WineHQ stable 10.0**, pinned. | 11.0 aborts in `ntdll/unix/virtual.c` (`anon_mmap_fixed`) under emulation; distro Wine 9.0 runs MWCC but cannot load the Nitro SDK tools (fixed base 0x400000, no relocs: `status c0000018`). |
| 2026-10-30 | `install-ds-toolchain.sh` transcodes the two LCF templates from cp932 to UTF-8 (installed copies only). | SDK 4.2-jp templates have Shift-JIS comments; the decomp's Python scripts read UTF-8. | (A no-op with the 3.2 SDK, whose templates are ASCII.)
| 2026-10-30 | `CC` is unset when building the Platinum port (it honours `CC ?= cc`); the container's `CC=gcc-10` makes it fail on unnamed parameters. | Platinum CI uses the distro default gcc. | **Superseded 2026-10-31: patch 1201 fixes the unnamed parameter and the other gcc-10 errors, so the vendored port is built with `CC=gcc-10` (the image default). Platinum CI still uses its default gcc.** |
| 2026-10-31 | SDK patches are new HGSS patches numbered by area (0101 fx, 0201 small hw, 0301 one-offs, 0401 os_system, 0501 cp/os context, 0601 port hooks, 0701 card SPI, 0801 qsort, 0901 irq handler; pokeheartgold 1001 types) rather than a 1:1 rebase of Platinum's 0001-0027. | Platinum's patches cannot be applied to HGSS's differently organised SDK; the triage found only 4 trivial, 16 moderate, 3 rewrite, 4 N/A. Each patch cites its Platinum counterpart. |
| 2026-10-31 | Every asm-to-C hunk uses `#ifdef SDK_PORT_3DS` C version `#else` original `#endif`, and is proven DS-neutral with `gcc -E -P` (identical output without the macro) plus a host test with a mutation check. | Hard rule 3; MWCC must compile exactly the original text. |
| 2026-10-31 | `OS_SaveContext`/`OS_LoadContext` C versions do not call `CP_SaveContext`/`CPi_RestoreContext`. | The port's `HandOver` (port_thread.c:203,228) already does it per thread; a restore before the switch would overwrite the leaving thread's CP state. |
| 2026-10-31 | Channel-0 "dummy DMA" is skipped under the port. | Same effect as Platinum 0009 (`MIi_DUMMY_DMA_NO` = 0xFFFFFFFF); otherwise the dummy overwrites the real transfer's registers. |
| 2026-10-31 | GX FIFO sends in 0201 use plain stores; routing through the port's 3D translator is deferred to a `g3imm` patch with the caller-side change (Platinum 0024). | HGSS `g3imm.c` stores the opcode with a plain store before the send; hooking only the send would feed matrix words to the packed-command decoder. |
| 2026-10-31 | `OS_ReleaseLockID` follows the HGSS ARM shift semantics (low byte of the offset), not Platinum 0015's guard. | HGSS asm is the source of truth; only invalid IDs >= 0x160 differ. |
| 2026-10-31 | `make test` = tool tests + `tests/sdk/*`; `port-tests` is a separate target that fails until the port wiring exists; the layout probe is local (needs MWCC). | CI must not report green for the unmet exit criterion, nor red for a known placeholder. |
| 2026-10-31 | `u64`/`s64` are `aligned(4)` under `SDK_PORT_3DS` (pokeheartgold patch 1001). | Measured: without it devkitARM and `-malign-double` differ from MWCC in 55 save-struct values (tools/layout_probe). |
| 2026-10-31 | The vendored port is built with gcc-10 (`CC` in the image); the SDK survey defaults to gcc 13 and both numbers are recorded. | The port's host32 build is gcc-10; a file can parse under 13 and fail under 10 (SND_command.c did). Neither is a gate on its own. |
| 2026-10-31 | Under `SDK_PORT_3DS`, `HW_*` memory areas are the port's arrays via expressions `(u32)array + offset` (patch 1301), and the two absolute MI DMA register literals are derived from `HW_REG_BASE` (patch 1302). | Follows Platinum 0001/0005, re-derived from HGSS's headers. The 64-bit `host` target cannot use this (the cast truncates); `host32` and the 3DS can. |
| 2026-10-31 | SDK host suites link `tests/sdk/port_memory.c` for the port arrays, and `card_spi_wait` guards the whole I/O array with `mprotect` instead of mapping `0x04000000`. | The registers are no longer at the fixed DS address after 1301; guarding the array keeps the "a register touch faults" check alive. |
| 2026-10-31 | HGSS names for Platinum headers go in the tracked `hgss/compat/include/`, on the `hgss_nitro.py` include path, not in edits to vendored files. | Keeps `3ds_port/` close to Platinum for upstream; the shim already points at the directory. |
| 2026-10-31 | The current state is kept in `docs/progress/STATE.md` and rewritten in place; phase records are append-only with dated updates. | Resuming needs one current page, not a diff of eleven agent notes. |
