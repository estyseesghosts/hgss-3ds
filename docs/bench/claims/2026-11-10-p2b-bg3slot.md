# Claim sheet: P2b BG3SLOT (front-region commits)

```text
Hypothesis:               Enabling the third BG slot lets front-region text
                          commit as GPU quads instead of CPU raster + upload
                          (front commits non-zero, no new reject bucket grows),
                          without changing pixels.
Target scene:             Frozen Goldenrod save, hg-continue-field.txt (rest)
                          and hg-field-walk.txt, frames 9000+.
Target hardware:          Old 3DS; Azahar 2126.2 O3DS-sim for activation and
                          work proof. Costs on hardware (final packet pair).
Baseline artifact:        PROFILE dc183349… (620fa70, dirty no, default flags;
                          code-identical to HEAD apart from docs-only commits).
Candidate artifact:       PROFILE +BG3SLOT (same tree, env flag only; SHA
                          recorded at build).
Activation proof:         Front-region commits non-zero in both scripts
                          (P1 gpubg counters: front commits; reject buckets
                          printed per reason).
Work proof:               Map + tile bytes walked per 600 ticks fall in
                          proportion to the commit rate (P1 keyMap/keyTile);
                          rasterised scanlines fall; texture upload bytes fall
                          or hold. No reject bucket grows vs baseline (BG3
                          alpha states are known software fallbacks — counted,
                          not hidden).
Correctness proof:        Captures at fixed script frames unchanged from
                          baseline; battle/menu/title regression (BG3 layout
                          change is the risk); `make tool-tests` no new
                          failure. Do NOT weaken the shared-struct-layout
                          regression test; update it to the new default.
Hardware result:          Paired A/B on the console (owner run).
Regression surface:       Battle, title, menus, transition, audio, sleep/close.
Conclusion:               not established (code not built).
Next decision:            keep (flip default; env 0 disables) / revert if no
                          front commits fire or any reject bucket grows.
```
