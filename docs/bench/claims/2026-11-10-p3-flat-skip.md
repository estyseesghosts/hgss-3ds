## Dependency list (every input the flat picture depends on)

Covered by `EngineSmallSignature(e, snapshot, mask, 0, 0)` with `mask` =
committed text BGs (exactly as the non-flat reuse branch): display registers
(0x70, minus the 3D ack bits that flap every frame and MASTER_BRIGHT, which
the compositor applies on GPU), VRAM bank control (VRAMCNT), POWCNT swap bit,
BG palettes, OAM (incl. affine-vs-hidden semantics, which live here, not in
the VRAM range), per-line registers when active. Covered by
`SplitLayoutSignature`: canvas width/origin/clip, anchorWindows,
windowsToEdge, snapshot/height/top/stretch/gpuBgs, smooth-OBJ flag,
wide-windows serial, wide-art serial, window circles. Covered by the
referenced-range VRAM signature (`EngineReferencedOnly`, the referenced range
only, when modelled): map bytes, tile bytes and palettes the frame's layers
can actually read. Covered by the scroll check: committed-BG HOFS/VOFS
(scroll-only frames re-render). Covered by `RememberSplit` extension:
small+vram+scroll stored only when a flat render completes; the retained
quads/slots the caller keeps.

Not covered (take today's Render path): frames the referenced-range
signature does not model (`modelled == 0` — no fallback to the full 864 KB
hash here); non-flat pictures; engine B paths (untouched); any case the
diagnostic disagrees on (stop, do not ship with forced redraws).

## Implementation (what the code does)

`3ds_port/nitro/src/port_render2d.c`:

- `EngineReferencedOnly()`: the referenced-range signature **only**. Unlike
  `EngineVramSignature()` it never falls back to the full-VRAM hash: a frame
  the referenced set cannot model is reported "not modelled" and the caller
  keeps today's path (the plan's rule 2).
- `FlatStore()` (called from `RememberSplit()` when the render was flat):
  keeps `EngineSmallSignature(e, snapshot, mask, 0, 0) * 31 ^ layout`, the
  referenced-range VRAM signature and the committed BGs' scroll. The VRAM
  signature is only kept when `refHashA` is on: the skip rides that switch,
  and without it there is no signature that could stand in for the full hash
  (which must not be paid here).
- `FlatUnchanged()`: recomputes the same pair and compares, then checks the
  committed BGs' scroll. Returns 0 (today's path) if the frame is not
  modelled, if either signature differs, or if a committed BG scrolled.
- The flat branch of `NitroPort_Render2DSplitIfChanged()` skips the pass only
  when the picture is the same **and** the under/over/overAlpha buffers are
  the ones the picture was drawn into (the same condition the existing reuse
  branch uses).
- The diagnostic (`refHashDiag`): the pass always runs, and what it published
  (quad count, quad contents, slot keys, backdrop, has3d, scroll3d, tint3d,
  eva/evb/evy, flat flag) is compared with what the last flat pass published.
  A difference is counted and logged; the pass is redrawn either way.
- Counters: `NitroPort_Render2DFlatStats()` -> the shell's `[perf] flatskip:`
  line (skipped / redrawn / not-modelled / disagreements, and which input
  differed when a pass did not skip: small / vram / scroll / buffers). The
  "why" fields are what make a zero-skip result explainable instead of a
  mystery.

Both builds skip (it is a behaviour change, not instrumentation); the OFF
build is the timing build.

### Two places the plan's wording is not what the code does

1. The plan says "the caller already republishes the retained layers". It
   does not publish a new layer *set*: `RenderScreen()` returns false, so no
   `NitroPort_ComposePublish()` happens; the drawer marks the retained set
   current (`NitroPort_Compose2DCurrent()`) and the compositor keeps using
   the previous publication. The effect is the one the plan wants (the
   picture on screen stays, the 3D keeps composing), and it is the same path
   the existing reuse branch takes.
2. The plan's dependency list says the referenced-range signature is computed
   "only if" it models the frame. Modelling is only known after the
   computation, so the cost of the first, unmodelled attempt is paid. It
   bails at the first unmodelled BG, so it is bounded by one BG's map.

## Run manifest

Manifests + trial logs under `build/bench/ab-p3-{field,walk}/` plus the

## Notes

- In split mode the software picture does not read the 3D image: a new 3D
  scene is not a reason to redo the flat picture.
- Never cache anything keyed on a pointer; never treat a scroll-only frame
  as unchanged (scroll check, not signatures).
- P4 (VRAM-read race) is a separate packet: it measures, in this diagnostic
  mode, whether the double-hash disagrees within a pass.
